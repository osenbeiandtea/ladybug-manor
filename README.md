# Ladybug Manor — てんとう虫の館

3Dの洋館で、かくれたてんとう虫を探す絵探しパズル。
十七の夏、てんとう虫を追いかけた令嬢は、この館から姿を消した——。

- 部屋: 玄関ホール / 応接室 / 図書室 / 令嬢の寝室 / 書斎
- 遊び方: ドラッグで見回して、引き出しや本をタップ。各部屋に3匹のてんとう虫がいます。
- 技術: Three.js (r128) の単一HTML。ビルド不要、GitHub Pagesでそのまま公開できます。
